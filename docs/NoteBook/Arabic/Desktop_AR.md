# إذاعة القرآن الكريم 98.2 (القاهرة) — تطبيق سطح المكتب

غلاف سطح مكتبي (Windows / Desktop shell) مبني باستخدام Electron لنفس مشغل الراديو المباشر ثنائي اللغة لإذاعة القرآن الكريم 98.2 (القاهرة).

**الحالة اعتباراً من 2026-09-20:** الكود مكتمل (المرحلة 2)، ولكن تشغيل الصوت المباشر وحزمة التثبيت لم يتم التحقق منهما في بيئة البناء الحالية لغياب الاتصال المفتوح بالإنترنت — يُعامل ككود غير مفعل لحين تجربته على جهاز بدون قيود.

---

### ما هو التطبيق
غلاف إلكترون خفيف (`packages/desktop`, `@quran-fm/desktop`) يغلف نفس البناء الاستاتيكي الخاص بتطبيق الويب (`packages/web/dist`) — لا توجد قاعدة كود منفصلة لواجهة سطح المكتب. ويضيف الغلاف الوظائف التالية:

---

### المعمارية البرمجية (Architecture)
```
packages/desktop/
├── electron/
│   ├── main.js       # التعامل مع نافذة المتصفح، صينية النظام (Tray)، وتشغيل الخلفية
│   ├── preload.js    # contextBridge -> window.desktop (مزامنة تشغيل/إيقاف صينية النظام)
│   └── icon.png       # أيقونة مؤقتة بحجم 1x1
└── README.md
```

* **ملف `electron/main.js`:** يقوم بتحميل رابط خادم التطوير (Vite) أو ملف `index.html` المبنّي في `packages/web/dist/`.
* **صينية النظام (System Tray):** يبني القائمة السياقية ويقوم بتوجيه النقرات إلى واجهة العرض عبر IPC. يتم تقرير حالة التشغيل من `usePlayer` عبر `window.desktop.reportPlaybackState`.
* **الكائن `window.desktop`:** يكون غير معرف في متصفح الويب العادي، مما يحافظ على حزمة `@quran-fm/web` كبناء مشترك واحد.
* **عناصر التحكم في شاشة القفل ومفاتيح الوسائط:** لا تتطلب كوداً خاصاً بـ Electron، حيث يتم التقاط Web MediaSession API كأدوات تحكم ناطقة بنظام التشغيل (Windows SMTC).
* **التشغيل في الخلفية:** عند إغلاق النافذة، يتم إخفاؤها بدلاً من إنهاء التطبيق لضمان استمرار الصوت في الخلفية (`backgroundThrottling: false`). يتم الخروج الكامل فقط عبر خيار "خروج" الصريح في صينية النظام.

---

### التجميع والحزم (Packaging)
تستخدم حزمة `packages/desktop` أداة `electron-builder` لإخراج تثبيت NSIS `.exe` وحزمة MSI:
```sh
pnpm --filter @quran-fm/desktop dist
# أو: pnpm build:desktop
```
المخرجات في `packages/desktop/release/`:
* `Quran FM 98.2 Setup <version>.exe` — تثبيت NSIS
* `Quran FM 98.2 <version>.msi` — حزمة MSI

**متطلبات بناء حزمة MSI على Windows:**
* يتطلب أداة WiX Toolset v3.
* يفضل البناء على نظام Windows لنماذج msi/nsis.

---

### التشغيل المحلي
* **وضع التطوير (Dev mode):**
```sh
pnpm --filter @quran-fm/web dev
pnpm --filter @quran-fm/desktop dev
```
* **التشغيل ضد المخرجات المبنّية (Production):**
```sh
pnpm --filter @quran-fm/desktop start
```

---

### الاختبارات
لا يوجد نص اختبار آلي خاص بهذه الحزمة (`pnpm -r test` يتجاوزها). المنطق المشترك مغطى باختبارات `@quran-fm/core`. يتطلب السلوك المخصص لسطح المكتب مراجعة يدوية:
1. الضغط على تشغيل والتأكد من انطلاق الصوت.
2. تصغير/إغلاق النافذة والتأكد من استمرار التشغيل في الخلفية.
3. تجربة قائمة صينية النظام ومفاتيح الوسائط في نظام التشغيل.
4. الخروج الكامل عبر خيار "Quit" في صينية النظام.

---

### الفجوات المعروفة
* عدم إمكانية التحقق من تشغيل النافذة المباشرة في صندوق الرمل الحالي بسبب تلف تنزيل ملف ثنائي لـ electron (115MB).
* تعليمات حل مشكلة "Electron failed to install correctly" عبر إعادة تشغيل `node install.js`.
