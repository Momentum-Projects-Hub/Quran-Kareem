# إذاعة القرآن الكريم 98.2 (القاهرة) — تطبيق الويب

مشغل راديو مباشر ثنائي اللغة (العربية/الإنجليزية) لإذاعة القرآن الكريم من القاهرة — Quran FM 98.2 — تم بناؤه كتطبيق صفحة واحدة أُحادي المكونات (Static Single-Page App).

**الحالة اعتباراً من 2026-09-20:** مكتمل ومُنفذ ويعمل بالكامل (تم إكمال المرحلة 1 والمرحلة 1.1).

---

### ما هو التطبيق
مشغل راديو مباشر محدد لنطاق محطة واحدة على الويب. تم تصميمه بنطاق برمجي مخصص ونظيف: تجربة تشغيل مركزية واحدة فقط، وليس دليلاً للمحطات أو تطبيقاً للتصفح متعدد المحطات.

---

### التقنيات المستخدمة (Tech Stack)

| المجال | الخيار | السبب |
| ------ | ------ | ------ |
| الإطار (Framework) | React 19 + Vite + TypeScript | دورة تطوير سريعة خفيفة |
| التنسيق (Styling) | Tailwind CSS v4 (عبر `@tailwindcss/vite` بدون PostCSS) | تنسيق يعتمد على الأدوات المساعدة، ودعم سلس لخصائص الاتجاه من اليمين لليسار (RTL logical properties `ms-*`/`me-*`) |
| المنطق المشترك (Shared logic) | `@quran-fm/core` (حزمة ضمن المستودع) | حل رابط البث (Stream resolution)، نصوص الترجمة والتوطين (i18n)، والأنواع (Types) — مشتركة مع تطبيق سطح المكتب وتطبيق المحمول |
| إدارك الحالة (State) | React hooks + Context (`usePlayer`, `useLocale`) | التطبيق خفيف ولا يحتاج إلى تعقيد أطر مثل Redux أو Zustand |
| التدويل والتوطين (i18n) | قاموس مخصص بسيط (`packages/core/src/i18n`) | لغتان فقط وحوالي 10 مفاتيح ترجمة — لا حاجة لـ react-i18next |
| الاستضافة (Hosting) | Cloudflare Pages + GitHub CI/CD | استضافة استاتيكية مجانية، شبكة توصيل محتوى عالمية CDN، ونشر تلقائي عند الدفع للفرع الرئيسي |
| مدير الحزم (Package manager) | pnpm workspaces (Monorepo) | إدارة حزمة core المشتركة بين الويب وسطح المكتب والمحمول بدون تضارب الإصدارات |

### تفاصيل التنفيذ
* **آلة حالة إعادة المحاولة والتراجع (Retry/Backoff State Machine):** تعيش هذه الآلة المستقلة عن الإطار في حزمة `@quran-fm/core` (`streamResolver.ts`) وتُدار عبر محول مستند إلى HTMLAudioElement (`packages/web/src/player/audioAdapter.ts`)، مما يعيد استخدام نفس المنطق في المحمول بدون تكرار.
* **واجهة `EnhancedPlayer`:** بطاقة مشغل رئيسية بتصميم الزجاج الضبابي (Glassmorphism: `border-white/10 + bg-white/5 + backdrop-blur-xl`)، وأعمدة تسوية صوتية متحركة بـ CSS فقط، وزر تشغيل نابض أثناء عمل الصوت.
* **خاصية `preload="none"`:** مضافة على عنصر `<audio>` لضمان عدم التحميل المسبق للبث المباشر.
* **الخطوط:** خطوط Google Fonts (Cairo / Tajawal) مُطبقة عبر قواعد CSS لضمان قراءة ممتازة للنصوص العربية.
* **تبديل اللغة:** زر أيقونة الكرة الأرضية (🌐) في الزاوية العلوية (متوافق مع اتجاه RTL).
* **زر المشاركة `ShareButtons.tsx`:** روابط مشاركة لفيسبوك وواتساب وتليجرام، بالإضافة إلى زر Web Share API المدمج.
* **الأعمال الفنية المضمنة:** شعار ومؤثرات بصرية محلياً (`public/station-artwork.svg`) دون الاعتماد على خوادم صور خارجية.
* **سياق اللغة `LocaleContext.tsx`:** يحفظ خيار اللغة في `localStorage` ويقوم بتبديل اتجاه `dir` واللغة `lang` في عنصر `<html>`.
* **واجهة MediaSession API:** توفر عناصر التحكم في شاشة القفل ومفاتيح الوسائط على سطح المكتب والويب.
* **تكامل سطح المكتب:** يكون `window.desktop` غير معرف في متصفح الويب العادي، مما يسمح باستخدام نفس البناء للبث في الويب وسطح المكتب.

### التشغيل المحلي
```sh
pnpm install
pnpm --filter @quran-fm/web dev       # http://localhost:5173
pnpm --filter @quran-fm/web build     # ينشئ packages/web/dist/
pnpm --filter @quran-fm/web preview   # التحقق المحلي من النسخة الإنتاجية
pnpm --filter @quran-fm/web lint      # فحص الكود عبر oxlint
```

---

### الاختبارات
مستندة إلى Vitest + Testing Library (jsdom):
```sh
pnpm --filter @quran-fm/web test
```
* **تغطي:** عرض حالة انقطاع الاتصال (إظهار روابط الاستماع الخارجية) وتبديل اللغة والاتجاه RTL.
* **التحقق اليدوي:** تشغيل الصوت المباشر، سلوك انقطاع الشبكة وإعادة المحاولة، وتبديل اتجاه الواجهة RTL/LTR.

---

### الفجوات والمهام المفتوحة
* لم يتم اختبار تشغيل الصوت في المتصفح تحت ظروف شبكة حقيقية داخل بيئة البناء الحالية (تم التحقق من رابط البث عبر curl).
* واجهة تصفح المحطات الأخرى من API (MP3Quran) موجودة في الحزمة المرجعية لكنها غير مفعلة في الواجهة حالياً.
